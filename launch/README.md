# 🚀 Nexus-Agent Global & Domestic Viral Launch Kit

이 디렉토리는 **Nexus-Agent (v1.0.0)**를 전 세계 및 국내 핵심 개발자 커뮤니티에 효과적으로 확산시키기 위해 기획된 **즉시 배포용 바이럴 패키지**입니다.

모든 자료는 각 커뮤니티의 문화, 성향, 기술적 톤앤매너에 맞추어 최적화되었습니다.

## 🎯 바이럴 배포 권장 순서 & 골든 타임

1. **Phase 1: 글로벌 선공개 (Hacker News & Reddit)**
   - **타이밍**: 한국 시각 21:00 ~ 23:00 (미국 서부 오전 05:00~07:00, 동부 오전 08:00~10:00 출근 시간대)
   - Hacker News "Show HN" 등록 후 즉시 첫 댓글로 기술적 동기 설명.
   - Reddit `r/LocalLLaMA` 및 `r/Python`에 기술적 차별점(AST 검증, Time-Travel Rollback, 오프라인 Mock) 강조 포스팅.

2. **Phase 2: 국내 테크 커뮤니티 등록 (GeekNews & Velog)**
   - **타이밍**: 한국 시각 오전 08:30 ~ 09:30 (출근 시간대 트래픽 집중)
   - GeekNews에 깔끔하고 정제된 한국어 소개 등록.
   - Velog에 "내가 혼자서도 시니어 엔지니어 군단을 가진 것처럼 코딩하는 법" 심층 개발기 발행.

3. **Phase 3: 실시간 확산 (X/Twitter & 개발자 디스코드)**
   - Phase 1, 2의 링크를 X(트위터) 스레드로 엮어 인용 RT 유도.
   - AI Korea, GPTers, 파이썬 사용자 모임 디스코드의 `#오픈소스-홍보`, `#프로젝트-공유` 채널에 공유.

## 💡 바이럴 핵심 차별화 포인트 (USP)
- 🧠 **자율 ReAct 루프 + 자가 치유(Self-Healing)**: 코드를 생성하고 스스로 pytest를 돌려 에러를 고칩니다.
- 🛡️ **AST 구문 사전 검증**: 문법 에러가 있는 코드는 디스크에 기록조차 되지 않습니다.
- ⏱️ **타임 트래블 롤백**: 에이전트가 코드를 망치더라도 1ms 만에 과거 스냅샷으로 1클릭 복구.
- 💰 **Zero API Key 오프라인 데모 모드**: API 키 없이도 누구나 `start.bat`만 누르면 즉시 작동 확인 가능.
- 🎨 **사이버펑크 글래스모피즘 Web UI**: 터미널뿐만 아니라 직관적인 대시보드와 ChatGPT 스타일 대화 제공.
